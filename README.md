# Katara's Campaign

A private D&D 5e campaign set in the Forgotten Realms with a homebrew North Pole and a trail of magical Wonders. Judy (a Christmas elf fighter), Dormir (a dwarf cleric) and Lyric (a halfling bard) chase The Hawk, who is collecting six Wonders that can rewrite reality.

This repo is the DM's source of truth for maintaining the campaign and building future sessions, used with Claude Code as a co-DM. See [CLAUDE.md](CLAUDE.md) for the assistant's operating brief.

## Structure

| Folder | Contents |
|---|---|
| `campaign/` | Overview, the Six Wonders spine, plot threads, name index, tone guide |
| `characters/` | The three PCs (reference only) |
| `sessions/` | Session records and prep docs |
| `npcs/`, `locations/`, `factions/` | Who and where |
| `props/` | Player handouts and PDF generators |
| `rules/` | House rules, loot and potion tables |
| `legacy/` | Original Drive docs, verbatim, for reference only |
| `.claude/skills/` | Writing voice, session review, and handout skills |

Docs are markdown, written to be pasted straight into Google Docs for the table.

# Splitting player-facing props from GM material

## The rule
**A player-facing prop shows only what an in-world version of that document would plausibly contain.** The test for every section: would the in-world author actually write this down for a stranger to read? If the answer is "only if they were secretly working for the DM," it does not belong.

Worked example from the old Session 2 handouts (`legacy/Session 2 - Player Handouts.md`):
- **Good:** Santa's burned note shows only the words that survived the fire. The burned words stay in the GM note.
- **Good:** Noelle's torn diary page reads as a diary. It never states the crime. The DM note says which two lines do the work.
- **Needs care:** the Naughty & Nice List is a joke prop, so the in-jokes stay in. The "different handwriting, ink still tacky" detail is a clue the players see, but the explanation of why (the List wrote it itself) is GM-only.

## Where the cut content goes
Never delete it, move it. GM-only material belongs in the matching `sessions/Session N Prep.md`: full lists, secret motives, DC tables, what burned or torn text says, anything that exists to help run the scene. Confirm each removed section has a home in the GM doc before deleting it from the player-facing one.

## Props for this table
- **Props Katara can hold are the best tool in the campaign.** A worksheet, a card, a list she can mark up.
- **Do not hand a veteran a prop meant as Katara's spotlight.** If a prop is one player's tool, give the others their own thing to care about.
- **Do not put mechanics or DCs on a player-facing prop** unless it is an item card, and then only the rules text.

## Common failure modes
- **Scope creep during a long build.** A prop starts small and accretes GM content pass by pass. Re-run the test on the whole doc periodically.
- **Stale cross-references after a trim.** Check every "see page N" after any page-count change.
- **Genuinely ambiguous content.** The test is whether a real person in that world would know and casually print it, not whether it is spoiler-adjacent. When unsure, ask.

## Before finalizing
Walk the player-facing file section by section against the test. Anything that fails goes to the GM doc. Then re-check cross-references.
